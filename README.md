## Как выложить

1. Создайте репозиторий (например, `MLBBB-groups`).
2. Загрузите **всё содержимое этой папки** в корень репозитория
   (`index.html`, `.nojekyll`, `README.md` и папки `1a` … `1tg-2`).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка **/ (root)** → Save.

На открытке: фото группы, «25 ноября приглашается», код группы, классный руководитель.
Фото человека, время и награда убраны; после приглашения ничего нет.
